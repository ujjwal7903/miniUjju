# miniUjju

A little code, a lot of curiosity, and the occasional detour - welcome to **Ujjwal Keshri's** corner of the internet.

## Preview

Open [`index.html`](index.html) in a modern browser. No installation, build step, API key, or local server is required. The portfolio and its local illustrations work offline; external links need an internet connection.

## What's inside

- Selected work across Windows, Windows 365, and AI experiences, with expandable project details.
- A career and education timeline, skills, community work, and achievements.
- An interactive atlas of places in India and Japan, with illustrated destination notes.
- A photo album, original miniUjju mascot, and contact links.
- Responsive layouts, keyboard-friendly navigation, and reduced-motion support.

## Project structure

| Path | Contents |
|---|---|
| `index.html` | Portfolio content and page structure |
| `css/` | Base styles, components, page sections, animations, and responsive styles |
| `js/app.js` | Initializes the interactive features |
| `js/data/` | Destination and postcard illustration data |
| `js/features/` | Atlas, navigation, and contact interactions |
| `assets/album/` | Portfolio photographs |
| `assets/maps/` | Local map artwork and attribution |
| `assets/icons/` | Local icons and license information |

## Deploy with GitHub Pages

This is a static website. In the repository on GitHub, open **Settings > Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save. GitHub Pages will publish `index.html` from the repository root.
